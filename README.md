# Windows Temp Cleaner
Легковесная и надежная консольная утилита на C++17, созданная для безопасной очистки папки `Temp` в Windows и освобождения места на диске.

## 🚀 Особенности программы
- **Автоматический поиск:** Самостоятельно находит путь к временным файлам текущего пользователя через системные переменные окружения (`LOCALAPPDATA`).
- **Защита от вылетов:** Благодаря встроенной обработке ошибок (`try-catch`), программа безопасно пропускает файлы, которые прямо сейчас заняты системой или другими программами (например, браузером), не аварийно завершая работу.
- **Наглядная статистика:** В конце работы выводит точное количество удаленных и пропущенных файлов.
- **Поддержка UTF-8:** Корректно отображает русский текст в консоли Windows без «кракозябр».

## 🛠️ Системные требования
- **ОС:** Windows
- **Компилятор:** GCC (MinGW / MSYS2) или любой другой с поддержкой стандарта C++17.

## 🔨 Как скомпилировать (Автономный EXE)
Чтобы собрать полностью независимый `.exe` файл, который запустится на любом компьютере без ошибок об отсутствии `.dll`, используйте следующую команду в терминале MSYS2 / MinGW:

```bash
g++ -O3 line.cpp -o SystemCleaner.exe -static-libgcc -static-libstdc++ -static
```

*Примечание: Если ваш файл с кодом называется иначе, замените `line.cpp` на ваше имя файла.*

## 💻 Использование
Просто запустите скомпилированный файл `SystemCleaner.exe`. Программа выполнит очистку и выведет результаты. Чтобы окно консоли не закрылось мгновенно после завершения работы, утилита дождется нажатия клавиши `Enter`.
